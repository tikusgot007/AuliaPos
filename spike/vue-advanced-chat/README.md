# Spike: vue-advanced-chat untuk thread pesan Inbox

Prototipe sekali pakai (bukan kode produksi) untuk menjawab apakah `vue-advanced-chat@2.1.2` (UMD dari CDN jsDelivr, tanpa build step) layak menggantikan panel thread di `app/Views/inbox/index.php`; instruksi dan kriteria K1-K11 ada di `docs/rencana-spike-vue-advanced-chat.md`, hasilnya di `docs/laporan-spike-vue-advanced-chat.md`. Cara menjalankan: `node make-fixtures.js` (membuat `fixtures.json`, `fixtures-500.json`, `media/*.png`), `node serve.js 8765` lalu buka `http://localhost:8765/` (atau `python3 -m http.server 8765`); untuk uji otomatis pasang Playwright di luar repo, jalankan `node build-baseline.js` (menyalin fungsi render `v2.4` ke `baseline.html`, di-ignore git) lalu `PLAYWRIGHT_MODULE=<path playwright> CHROMIUM_PATH=<chromium> CDN_CACHE=<folder berkas CDN> node run-spike.js [k1,k2,k3,k4,k5,k6,k8,k10]`, yang menulis `results.json` dan `screenshots/`. `CDN_CACHE` (berisi `vac.umd.js`, `bootstrap.css`, `fa.css`, `emoji.json`, `webfonts/`) diperlukan hanya karena Chromium di sandbox tidak memercayai CA proxy; berkas itu diunduh dengan `curl` dari URL CDN yang sama (TLS terverifikasi) dan disajikan lewat `page.route`. Berkas: `adapter.js` (pemetaan baris API ke model library), `slots.js` (isi slot `message_{id}`), `media.js` (state machine media gagal, disalin dari `v2.4`), `main.js` (glue: mount, polling, sinkron slot, aksi), `spike.css` (CSS bubble yang disalin dari `index.php`), `count-loc.js` (penghitung baris untuk K2).
